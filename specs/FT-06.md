# FT-06 Manajemen Data Terapis (Tambah dan Kelola Staf)

Sumber PRD: FT-06, BL-02, Permintaan Iterasi Pengguna (Tambah Terapis Baru)

## Tujuan
Memungkinkan admin melihat, menambahkan terapis baru tanpa batasan 3 staf, serta mengubah nama dan status aktif seluruh terapis klinik.

## Alur
1. Admin membuka menu Terapis.
2. Sistem menampilkan daftar terapis yang terdaftar beserta status aktif dan keterkaitan akun login.
3. Admin dapat menekan Tambah Terapis untuk menambahkan terapis baru (dengan opsi langsung membuatkan akun login).
4. Admin dapat mengubah nama atau status aktif tiap terapis lalu menyimpan perubahan (termasuk ke tab `Terapis` Google Sheets bila terhubung).

## Data
- `DEFAULT_THERAPISTS` (3 terapis awal bawaan)
- `SHEET_TABS.therapists`

## Aturan dan rumus
- Kapasitas simultan klinik menyesuaikan jumlah terapis yang berstatus `is_active === true`.
- Nama terapis wajib diisi; tidak boleh kosong atau hanya spasi.
- Terapis dengan `is_active === false` tidak dapat dipilih untuk reservasi baru, namun riwayat reservasi lamanya tetap tampil.

## Input dan validasi
- Nama terapis: wajib diisi (contoh: `Maya Kusuma`).

## Tampilan dan teks
- Menampilkan tombol "Tambah Terapis" di bagian atas daftar terapis.
- Setiap baris menampilkan ID, kolom nama, status akun login terhubung, serta tombol status `Aktif` / `Nonaktif`.

## Kasus uji
| ID | Input | Hasil yang diharapkan | Sumber |
| :--- | :--- | :--- | :--- |
| Tambahan-1 | Tambah terapis ke-4 bernama `Maya Kusuma` | Kolom ke-4 langsung muncul di kalender harian dan daftar pilih terapis formulir reservasi | Tambahan |
| Tambahan-2 | Nonaktifkan salah satu terapis | Terapis bertanda Nonaktif tidak dapat dipilih pada reservasi baru | Tambahan |

## Di luar lingkup
- Penghapusan permanen terapis yang sudah memiliki riwayat reservasi (gunakan status `Nonaktif` agar riwayat tetap utuh).
