# FT-08 Rekapitulasi Pendapatan Harian, Mingguan, dan Bulanan

Sumber PRD: Permintaan tambahan pengguna pada menu aplikasi untuk rekapitulasi pendapatan berbasis harian, mingguan, dan bulanan atas layanan yang dihasilkan.

## Tujuan
Admin klinik dapat melihat, menyaring, dan mengekspor rekapitulasi pendapatan harian, mingguan, dan bulanan berdasarkan layanan yang dihasilkan.

## Alur
1. Admin membuka tab **Pendapatan** pada bilah navigasi atas.
2. Admin memilih rentang rekapitulasi: **Harian**, **Mingguan** (Senin sampai Minggu), atau **Bulanan**.
3. Admin memilih tanggal, minggu, atau bulan acuan menggunakan tombol navigasi atau pemilih tanggal/bulan.
4. Admin memilih cakupan status reservasi: **Selesai Saja** (bawaan, layanan yang telah selesai) atau **Selesai + Terjadwal** (proyeksi).
5. Sistem menampilkan ringkasan total pendapatan, rincian per layanan, rincian per kategori (Pijat dan Facial), rincian per terapis, serta rincian kronologis periode terkait.
6. Admin dapat menekan tombol **Unduh CSV** untuk menyimpan laporan periode aktif ke file CSV.

## Data
- `CATEGORY_LABELS`, `STATUS_LABELS` dari `src/config.ts`.
- Data dinamis `bookings`, `services`, `therapists` dari state aplikasi (`localStorage` / Google Sheets).

## Aturan dan rumus
- Nilai pendapatan satu reservasi diambil dari `service.price` berdasarkan `booking.service_id` (bilangan bulat Rupiah). Jika `service_id` tidak ditemukan pada katalog, nilai dianggap `0`.
- Status `CANCELLED` (Dibatalkan) selalu dikecualikan dari seluruh perhitungan pendapatan.
- Mode **Hanya Selesai** (`COMPLETED_ONLY`): hanya menjumlahkan reservasi dengan `status === 'COMPLETED'`.
- Mode **Selesai + Terjadwal** (`INCLUDE_SCHEDULED`): menjumlahkan reservasi dengan `status === 'COMPLETED'` atau `status === 'SCHEDULED'`.
- Periode **Harian**: mencocokkan `booking.booking_date === targetDate` (`YYYY-MM-DD`).
- Periode **Mingguan**: mencocokkan tanggal Senin sampai Minggu (`startDate <= booking_date <= endDate`) yang memuat `targetDate`.
- Periode **Bulanan**: mencocokkan `booking.booking_date.startsWith(targetMonth)` (`YYYY-MM`).
- Potensi terjadwal (`scheduledPotential`) tetap dihitung dari reservasi berstatus `SCHEDULED` dalam periode terpilih sebagai pembanding.
- Porsi persentase layanan = `Math.round((serviceRevenue / totalRevenue) * 100)` bila `totalRevenue > 0`, selain itu `0`.

## Input dan validasi
- Jenis periode: wajib salah satu dari `DAILY`, `WEEKLY`, `MONTHLY`.
- Tanggal acuan: format `YYYY-MM-DD` valid; bila kosong/tidak valid, mundur aman ke tanggal hari ini.
- Bulan acuan: format `YYYY-MM` valid; bila kosong/tidak valid, mundur aman ke bulan hari ini.
- Cakupan status: `COMPLETED_ONLY` (bawaan) atau `INCLUDE_SCHEDULED`.

## Tampilan dan teks
- Tab navigasi **Pendapatan** khusus untuk peran `ADMIN`.
- Strip ringkasan utama menampilkan total pendapatan (`tabular-nums`, format `Rp150.000`), jumlah sesi terhitung, dan potensi dari jadwal berstatus `Terjadwal`.
- Tabel **Pendapatan per Layanan** menampilkan nama paket layanan, kategori, jumlah sesi, harga satuan, total pendapatan, dan porsi persentase.
- Tabel **Rincian Periode** menampilkan daftar sesi (untuk Harian), ringkasan Senin–Minggu (untuk Mingguan), atau ringkasan per minggu kalender (untuk Bulanan).
- Tabel **Pendapatan per Terapis** menampilkan jumlah sesi dan total kontribusi pendapatan per terapis.
