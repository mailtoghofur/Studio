# FT-05 Pengelolaan Status, Pembatalan Jadwal, dan Cetak Resi

Sumber PRD: FT-05, BL-02, BL-05, AC-06, TC-08, serta Permintaan Cetak Resi dan Unduh PDF

## Tujuan
Memungkinkan pengelola dan terapis mengubah status reservasi (`Terjadwal`, `Selesai`, `Dibatalkan`), menjadwalkan ulang reservasi, mengunduh resi dalam format PDF, serta mencetak resi lewat sistem printer perangkat untuk reservasi yang telah berstatus `Selesai`.

## Alur
1. Pengguna mengeklik blok reservasi pada kalender harian.
2. Sistem menampilkan rincian pasien, layanan, waktu, terapis, lokasi/alamat, dan status saat ini.
3. Pengguna memilih aksi: `Tandai Selesai`, `Jadwalkan Ulang`, atau `Batalkan Jadwal`.
4. Untuk `Jadwalkan Ulang`, admin mengubah tanggal, jam mulai, atau terapis dengan validasi FT-04 (mengabaikan ID reservasi yang sedang diedit).
5. Saat status diubah menjadi `Selesai` (atau saat membuka kembali reservasi yang sudah berstatus `Selesai`), tombol **Cetak Resi** tampil di modal rincian untuk membuka pratinjau resi dengan pilihan **Unduh PDF** (`resi-<booking_id>.pdf`), **Cetak Resi** lewat dialog sistem printer browser, serta **Printer Termal** (jika browser dan port perangkat mendukung koneksi serial ESC/POS).

## Data
- `STATUS_LABELS`
- `LOCATION_LABELS`
- `CATEGORY_LABELS`
- `CLINIC_NAME`

## Aturan dan rumus
- Siklus status: `SCHEDULED` (`Terjadwal`), `COMPLETED` (`Selesai`), `CANCELLED` (`Dibatalkan`).
- Hanya status `SCHEDULED` yang mengunci slot terapis. Mengubah status ke `CANCELLED` mengembalikan slot agar dapat dipesan pasien lain.
- Saat *reschedule*, `booking_id` yang sedang diedit dikecualikan dari pemeriksaan bentrok milik dirinya sendiri.
- Fitur **Cetak Resi** dan **Unduh PDF** hanya aktif apabila `booking.status === 'COMPLETED'`.
- Nomor resi dibentuk dengan format `RESI-<booking_id>` dan total bayar membaca harga layanan bulat dari data layanan (`formatRupiah`).

## Input dan validasi
- Konfirmasi eksplisit wajib sebelum membatalkan jadwal (`CANCELLED`).
- Resi tidak dapat dibentuk untuk reservasi berstatus `SCHEDULED` atau `CANCELLED`.
- Jika dialog printer sistem diblokir atau tidak tersedia, sistem menampilkan pesan kesalahan satu kalimat dan mengarahkan ke tombol **Unduh PDF**.

## Tampilan dan teks
- Dialog konfirmasi pembatalan menyebut nama pasien, waktu reservasi, dan perubahan status.
- Lembar pratinjau resi menampilkan logo klinik, nama klinik, nomor resi, waktu cetak, status `Selesai`, data pasien, layanan, jadwal, terapis, lokasi/alamat, total bayar (`tabular-nums`), dan ucapan terima kasih.
