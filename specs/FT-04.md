# FT-04 Validasi Slot Otomatis

Sumber PRD: FT-04, BL-01, BL-02, BL-03, AC-02, AC-03, AC-04, TC-01, TC-02, TC-03, TC-04, TC-05

## Tujuan
Mencegah penyimpanan jadwal yang melewati jam operasional 21.00 atau menyebabkan bentrok pada 3 terapis, sambil mengizinkan jadwal berurutan tanpa jeda waktu (0 menit).

## Alur
1. Setiap kali layanan, tanggal, atau jam mulai berubah pada formulir reservasi atau reschedule, sistem menjalankan kalkulasi slot.
2. Sistem mengevaluasi jam operasional (`T_start >= 10:00` dan `T_end <= 21:00`).
3. Sistem mengevaluasi irisan waktu terhadap seluruh reservasi berstatus `Terjadwal` untuk masing-masing dari 3 terapis pada tanggal yang sama.
4. Sistem menampilkan peringatan jelas jika waktu melewati 21.00, menandai terapis yang bentrok beserta jam bentroknya, atau menyatakan klinik penuh jika ketiga terapis terisi.

## Data
- `CLINIC_HOURS` (`openMinutes: 600`, `closeMinutes: 1260`, `bufferMinutes: 0`)

## Aturan dan rumus
- Jam operasional: `startMinutes >= 600` (`10:00`) dan `endMinutes <= 1260` (`21:00`).
- Rumus bentrok: `(T_start_baru < T_end_lama) && (T_end_baru > T_start_lama)`.
- Jeda 0 menit (`T_start_baru === T_end_lama`): tidak dihitung bentrok karena `end_lama > start_baru` bernilai `false`.
- Hanya reservasi berstatus `SCHEDULED` (`Terjadwal`) yang menahan kapasitas terapis.

## Input dan validasi
- Menolak simpan apabila `T_end > 21:00` dengan pesan menyebut batas jam operasional `10.00–21.00`.
- Menolak simpan apabila terapis terpilih memiliki irisan jadwal `SCHEDULED` dan menyarankan terapis lain yang tersedia.

## Tampilan dan teks
- Setiap opsi terapis menampilkan label status `Tersedia` atau `Tidak Tersedia` disertai alasan singkat (misal `Bentrok 13.00–14.30`).

## Kasus uji
| ID | Input | Hasil yang diharapkan | Sumber |
| :--- | :--- | :--- | :--- |
| TC-01 | Pijat 60 menit, mulai `20:30` | Ditolak karena selesai `21.30` (> `21.00`) | PRD |
| TC-02 | Pijat 60 menit, mulai `20:00` | Diterima, jam selesai tepat `21.00` | PRD |
| TC-03 | Terapis 1 terisi `13:00–14:30`; input baru `14:30–15:30` | Diterima tanpa peringatan bentrok | PRD |
| TC-04 | Terapis 1 terisi `13:00–14:30`; input baru `14:00–15:00` | Ditolak, Terapis 1 ditandai bentrok | PRD |
| TC-05 | 3 terapis terisi `15:00–16:00`; input ke-4 `15:00–16:00` | Tidak ada terapis tersedia, pemesanan ke-4 ditolak | PRD |

## Di luar lingkup
- Perhitungan estimasi waktu perjalanan antar-lokasi.
