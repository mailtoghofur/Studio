# FT-03 Formulir Pembuatan Reservasi

Sumber PRD: FT-03, BL-01, BL-02, BL-03, BL-04, AC-02, AC-03, AC-04, AC-05

## Tujuan
Memungkinkan admin mencatat reservasi pasien baru untuk layanan Pijat atau Facial beserta pemilihan lokasi, waktu, terapis tersedia, dan menyimpannya ke database lokal browser.

## Alur
1. Admin menekan tombol Buat Reservasi (atau mengeklik slot kosong / layanan hasil pencarian di kalender).
2. Admin dapat mengetik kata kunci di kolom **Cari Layanan** untuk menyaring daftar paket, lalu memilih layanan dari katalog (Pijat atau Facial).
3. Jika Pijat, admin memilih lokasi Di Klinik atau Di Tempat Pasien (wajib isi alamat). Jika Facial, lokasi otomatis terkunci ke Di Klinik.
4. Admin memilih tanggal dan jam mulai; sistem langsung menghitung jam selesai dan menampilkan status ketersediaan 3 terapis.
5. Admin memilih terapis berstatus Tersedia, mengisi nama serta nomor telepon pasien, lalu menekan Simpan Reservasi.
6. Sistem memvalidasi seluruh isian, lalu menyimpan reservasi ke database lokal dengan status `Terjadwal`.

## Data
- `CLINIC_HOURS`
- `LOCATION_LABELS`
- `STATUS_LABELS`

## Aturan dan rumus
- Jam selesai: `T_end = T_start + duration_minutes`.
- Jika `category === 'FACIAL'`, `location_type` dikunci ke `CLINIC` dan `patient_address` dikosongkan.
- Jika `category === 'PIJAT'` dan `location_type === 'HOME_SERVICE'`, `patient_address` wajib diisi.
- Nomor telepon Indonesia (`08xxx`, `+62xxx`, `62xxx`) dinormalisasi menjadi `62xxx` angka saja.
- Kolom pencarian layanan (`filterServicesByQuery`) menyaring pilihan pada dropdown paket layanan secara langsung berdasarkan nama, kategori, durasi, atau kode layanan.

## Input dan validasi
- Nama pasien: wajib (contoh: `Budi Santoso`).
- Nomor telepon: wajib, format Indonesia valid (contoh: `081234567890`).
- Layanan: wajib dipilih.
- Lokasi: wajib jika Pijat; terkunci `Di Klinik` jika Facial.
- Alamat pasien: wajib jika `Pijat - Di Tempat Pasien` (contoh: `Jl. Melati No. 12, Jakarta Selatan`).
- Tanggal & jam mulai: wajib, memenuhi batas 10.00–21.00.
- Terapis: wajib dipilih dan berstatus Tersedia.

## Tampilan dan teks
- Kolom **Cari Layanan** tampil di atas pemilih paket layanan dengan keterangan jumlah layanan cocok.
- Ringkasan waktu selesai otomatis tampil di dekat pemilih jam mulai.
- Saat ada error pada pengiriman formulir, pesan error muncul di bawah kolom terkait dan fokus pindah ke kolom error pertama.
