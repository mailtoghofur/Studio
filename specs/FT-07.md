# FT-07 Manajemen Akun dan Akses Master Sederhana

Sumber PRD: Bagian 10 (otentikasi admin), Permintaan Iterasi Pengguna (Login username/password lokal tanpa Google/Firebase, Manajemen Akun hanya melalui menu Manajemen Akun, Satu Akun Master dengan Paket Master JSON)

## Tujuan
Menyediakan sistem login username dan kata sandi lokal yang sederhana di browser dengan satu akun **Admin Master**, database terpisah per akun Admin, serta ekspor/impor Paket Master (`.json`) untuk memindahkan akun dan data antarbrowser tanpa Firebase atau server.

## Alur
1. Saat belum ada akun di browser, layar masuk meminta pembuatan satu akun **Admin Master** atau mengimpor file **Paket Master (`.json`)** dari browser lain.
2. Setelah akun Master dibuat, layar masuk hanya menampilkan formulir masuk (`Masuk Aplikasi Klinik`) tanpa tab pendaftaran akun baru.
3. Pembuatan akun baru (Terapis maupun Admin tambahan dengan pilihan `Gabung database ini` atau `Database baru terpisah`) hanya tersedia melalui menu **Manajemen Akun** oleh Admin.
4. Saat login sebagai Terapis, tampilan berfokus pada jadwal harian miliknya serta tombol untuk menandai sesi miliknya `Selesai`.

## Data
- `STORAGE_KEY` (`klinik_penjadwalan_v1`): daftar objek `UserAccount` (`account_id`, `username`, `display_name`, `role`, `therapist_id`, `owner_account_id`, `created_by_owner_id`, `is_master`, `salt`, `hash`, `is_active`, `created_at`, `updated_at`).
- `DB_KEY_PREFIX` (`klinik_db_<owner_account_id>`): database terpisah `AccountDatabase` berisi `therapists`, `services`, dan `bookings`.

## Aturan dan rumus
- Login memakai username dan kata sandi dengan hash SHA-256 ber-salt di browser (`crypto.subtle.digest`), tidak tersambung ke akun Google maupun Firebase.
- Akun **Admin Master** bersifat tunggal (`is_master: true`), tidak dapat dinonaktifkan atau dihapus.
- Setiap akun Admin baru di **Manajemen Akun** dapat memilih memakai database saat ini (`Gabung database ini`) atau membuat database lokal baru yang terpisah (`Database baru terpisah`).
- Akun Terapis terhubung ke `owner_account_id` milik Admin pembuatnya; jika dinonaktifkan (`is_active: false`), akses ditolak saat login.
- Untuk memakai akun Master dan data di browser lain, Admin dapat mengunduh `paket-master-naomi.json` dari tab **Database** lalu mengimpornya di layar masuk atau tab **Database** browser tujuan.

## Input dan validasi
- Nama pengguna: wajib diisi, minimal 3 karakter, tanpa spasi (contoh: `sari.terapis`).
- Kata sandi baru: wajib minimal 6 karakter, dan konfirmasi kata sandi harus cocok.
- Terapis terkait: wajib dipilih untuk akun berperan `THERAPIST`.

## Tampilan dan teks
- Modul akun berada di pojok kanan atas bilah navigasi, menampilkan nama pengguna/peran serta menu dropdown berisi `Manajemen Akun` (khusus Admin), `Ubah Kata Sandi`, dan `Keluar`.
- Saat menekan `Keluar`, sesi dikunci kembali ke layar masuk.
