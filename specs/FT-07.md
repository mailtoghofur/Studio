# FT-07 Manajemen Akun dan Akses Master Multi-Browser

Sumber PRD: Bagian 10 (otentikasi admin), Permintaan Iterasi Pengguna (Akun Admin Master multi-browser, Manajemen Akun hanya melalui menu Manajemen Akun)

## Tujuan
Menyediakan satu akun **Admin Master** dan akun Admin/Terapis yang tersimpan di cloud (Firebase Authentication Email/Password + Firestore) agar dapat diakses dengan username dan kata sandi dari berbagai browser dan perangkat.

## Alur
1. Saat sistem belum diinisialisasi (`system/meta` belum ada), layar masuk meminta pembuatan satu akun **Admin Master**.
2. Setelah akun Master dibuat, seluruh browser lain langsung menampilkan formulir masuk (`Masuk Aplikasi Klinik`) tanpa tab pendaftaran akun baru.
3. Pembuatan akun baru (Terapis maupun Admin tambahan dengan database bersama atau database baru terpisah) hanya tersedia melalui menu **Manajemen Akun** oleh Admin menggunakan instance sekunder Firebase Auth agar sesi Admin tetap aktif.
4. Saat login sebagai Terapis, tampilan berfokus pada jadwal harian miliknya serta tombol untuk menandai sesi miliknya `Selesai`.

## Data
- `system/meta` (`{ initialized, masterUid, createdAt }`)
- `admins/{uid}` (`{ uid, isMaster, workspaceId, createdAt }`)
- `users/{uid}` (`{ uid, username, display_name, role, workspace_id, therapist_id, is_active, is_master, created_by_uid, createdAt, updatedAt }`)
- `workspaces/{workspaceId}` beserta subkoleksi `members`, `config/therapists`, `config/services`, dan `bookings`.

## Aturan dan rumus
- Login memakai username dan kata sandi (dipetakan ke `<username>@naomi.klinik` pada penyedia Email/Password Firebase Authentication), tidak tersambung ke akun Google.
- Akun **Admin Master** bersifat tunggal, terlindungi di aturan Firestore (`is_master == true`), dan tidak dapat dinonaktifkan atau dihapus.
- Setiap akun Admin baru di **Manajemen Akun** dapat memilih memakai database saat ini (`Gabung database ini`) atau membuat ruang kerja database baru yang terpisah (`Database baru terpisah`).
- Akun Terapis yang dibuat di **Manajemen Akun** terhubung ke `workspace_id` milik Admin pembuatnya; jika dinonaktifkan (`is_active == false`), akses ditolak saat login dan oleh aturan Firestore.

## Input dan validasi
- Nama pengguna: wajib diisi, minimal 3 karakter, tanpa spasi (contoh: `sari.terapis`).
- Kata sandi baru: wajib minimal 6 karakter, dan konfirmasi kata sandi harus cocok.
- Terapis terkait: wajib dipilih untuk akun berperan `THERAPIST`.

## Tampilan dan teks
- Modul akun berada di pojok kanan atas bilah navigasi, menampilkan nama pengguna/peran serta menu dropdown berisi `Manajemen Akun` (khusus Admin), `Ubah Kata Sandi`, dan `Keluar`.
- Saat menekan `Keluar`, sesi dikunci kembali ke layar masuk.
