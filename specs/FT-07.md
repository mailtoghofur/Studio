# FT-07 Manajemen Akun dan Kunci Akses Lokal

Sumber PRD: Bagian 10 (otentikasi admin sederhana), Permintaan Iterasi Pengguna (Manajemen Akun Admin & Terapis)

## Tujuan
Menyediakan manajemen akun lokal berbasis peran (`Admin` dan `Terapis`) di browser tanpa kata sandi bawaan di kode, sehingga admin dan tiap terapis dapat masuk sesuai hak aksesnya.

## Alur
1. Saat aplikasi dibuka pertama kali dan belum ada akun tersimpan, sistem meminta pembuatan akun Admin Utama.
2. Pada kunjungan berikutnya, admin atau terapis masuk memakai nama pengguna dan kata sandi masing-masing.
3. Admin dapat membuka menu Akun untuk menambah akun login terapis baru, mengganti kata sandi (admin atau terapis), mengaktifkan/menonaktifkan akun terapis, atau menghapus akun terapis.
4. Saat login sebagai Terapis, tampilan berfokus pada jadwal harian miliknya (termasuk lokasi Di Klinik / Di Tempat Pasien dan alamat) serta tombol untuk menandai sesi miliknya `Selesai`.

## Data
- `STORAGE_KEY` (`klinik_penjadwalan_v1.accounts`: daftar akun `{ account_id, username, role, display_name, therapist_id?, salt, hash, is_active, created_at }`)

## Aturan dan rumus
- Tidak ada kredensial bawaan di dalam kode sumber; semua kata sandi dibuat pengguna dan disimpan sebagai hash SHA-256 bersalt acak.
- Nama pengguna harus unik (pemeriksaan *case-insensitive*).
- Minimal selalu ada satu akun `ADMIN` yang aktif (tidak dapat dinonaktifkan/dihapus jika merupakan satu-satunya admin aktif).
- Akun `THERAPIST` terhubung ke `therapist_id` tertentu; jika akun terapis dinonaktifkan, akun tersebut ditolak saat login.

## Input dan validasi
- Nama pengguna: wajib diisi, minimal 3 karakter, tanpa spasi (contoh: `sari.terapis`).
- Kata sandi baru: wajib minimal 6 karakter, dan konfirmasi kata sandi harus cocok.
- Terapis terkait: wajib dipilih untuk akun berperan `THERAPIST`.

## Tampilan dan teks
- Modul akun berada di pojok kanan atas bilah navigasi, menampilkan nama pengguna/peran serta menu dropdown berisi `Manajemen Akun` (khusus Admin), `Ubah Kata Sandi`, dan `Keluar`.
- Saat menekan `Keluar`, sesi dikunci kembali ke layar masuk.
