# FT-01 Tampilan Kalender dan Slot Harian 3 Terapis

Sumber PRD: FT-01, BL-01, BL-02, BL-03, AC-01

## Tujuan
Menampilkan jadwal harian seluruh 3 terapis secara berdampingan pada rentang operasional 10.00–21.00 setiap hari agar admin dapat memantau ketersediaan slot secara instan.

## Alur
1. Admin membuka halaman utama Jadwal Harian.
2. Admin memilih tanggal melalui tombol Hari Ini, Sebelumnya, Berikutnya, atau pemilih tanggal.
3. Sistem menampilkan 3 kolom terapis berdampingan dari pukul 10.00 sampai 21.00 beserta seluruh blok reservasi pada tanggal tersebut.
4. Admin dapat memfilter tampilan berdasarkan status reservasi atau mengeklik slot kosong untuk membuat reservasi pada jam dan terapis tersebut.

## Data
- `CLINIC_HOURS` (`openTime`, `closeTime`, `slotStepMinutes`, `bufferMinutes`)
- `STATUS_LABELS`
- `LOCATION_LABELS`

## Aturan dan rumus
- Klinik beroperasi 7 hari seminggu (Senin–Minggu) pukul 10.00–21.00.
- Rentang waktu kalender mencakup menit 600 (`10:00`) sampai menit 1260 (`21:00`).
- Blok reservasi diposisikan proporsional terhadap menit mulai (`start_time`) dan menit selesai (`end_time`) tanpa jeda antar-sesi (`bufferMinutes = 0`).

## Input dan validasi
- Pemilih tanggal menerima tanggal valid `YYYY-MM-DD` untuk hari apa pun sepanjang minggu.

## Tampilan dan teks
- Judul tanggal berformat Indonesia (contoh: `Jumat, 20 November 2026`).
- Ringkasan jam operasional `10.00–21.00` dan jumlah reservasi aktif.
- Setiap blok reservasi menampilkan rentang jam (`tabular-nums`), nama pasien, nama layanan, lokasi (`Di Klinik` / `Di Tempat Pasien`), dan status.

## Kasus uji
| ID | Input | Hasil yang diharapkan | Sumber |
| :--- | :--- | :--- | :--- |
| AC-01 | Buka jadwal pada hari Senin atau Minggu | Rentang jam 10.00–21.00 tampil untuk 3 terapis tanpa hari terkunci | PRD |
| TC-03 | Sesi 1 `13.00–14.30` dan Sesi 2 `14.30–15.30` pada terapis sama | Kedua blok tampil berurutan tepat di pukul 14.30 tanpa bentrok | PRD |
| Tambahan | Terapis berstatus nonaktif | Kolom tetap tampil dengan keterangan nonaktif dan slot tidak dapat dipesan | Tambahan |

## Di luar lingkup
- Tampilan kalender mingguan atau bulanan.
